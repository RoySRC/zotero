EpiLib desktop release

These packages are unsigned review builds, not notarized macOS or Authenticode-signed Windows installers. Operating-system security warnings may apply. Do not disable your operating system's security protections to install them. Maintainers should complete signing and platform smoke tests before promoting a draft for general distribution.

Download the archive for your platform. Quit EpiLib before replacing the application, keep a backup of your library, and retain your existing profile/data directory. Windows packages are portable ZIPs, not installers.

`SHA256SUMS` contains archive checksums. `epilib-update.json` is the EpiLib update feed. Checksums detect corruption; they are not an independent code-signing signature. EpiLib opens this release page for manual installation and never installs a Zotero binary update.

Source code is available through this release's source archives. Licenses and upstream attribution remain in the repository and bundled components.
